# 🧾 InvoiceKit — Invoice Generator with PDF Export

A clean, browser-based invoice generator that lets freelancers and small businesses create and download professional PDF invoices in seconds — no backend, no signup, no cost.

**[🚀 Live Demo](https://subaaishwaryas-ops.github.io/invoicekit)**

---

## ✨ Features

- **2 PDF Templates** — Modern (dark header) and Minimal (clean white)
- **Logo Upload** — Add your business logo to every invoice
- **Auto Calculation** — Subtotal, tax %, and total update live as you type
- **PAID Stamp** — Mark invoices as paid with one checkbox
- **Invoice History** — Re-download any previously generated invoice
- **Auto Invoice Numbering** — Invoice number increments automatically after each export
- **No Backend** — Runs 100% in the browser, zero server required
- **Free Forever** — No account, no subscription, no limits

## 🚀 Getting Started

No installation needed. Just open the file:

```bash
git clone https://github.com/subaaishwaryas-ops/invoicekit.git
cd invoicekit
# Open invoicekit.html in your browser
```

Or use the **[live demo](https://subaaishwaryas-ops.github.io/invoicekit)** directly.

> ⚠️ Requires an internet connection to load jsPDF from CDN.

---

## 📄 How to Use

1. **Business tab** — Enter your company name, email, phone, address, and optionally upload a logo
2. **Invoice tab** — Fill in client details, invoice number, dates, and line items
3. Pick a template (Modern or Minimal), set tax % if needed
4. Click **Download PDF** — your invoice downloads instantly
5. **History tab** — View and re-download all previously generated invoices
